# v1.3.0 compatible dependency remediation

- **Issue:** #6
- **Baseline:** `379bc33448b7190a4c2af6d4c4a98d91f8147773` (`security/v1.3.0-review`)
- **Advisory snapshot and source access date:** 2026-11-25
- **Scanner:** OSV-Scanner 2.7.1, scanning `poetry.lock` directly; counts below are advisory groups, with aliases grouped by the scanner.

## Changes and scope

- Refreshed compatible lock pins with Poetry 2.3.2. In particular, `certifi` moved from 2026.1.4 to 2026.11.20; `anyio`, `cryptography`, `idna`, `pydantic-settings`, `pygments`, `pyjwt`, `python-dotenv`, and `python-multipart` also moved to versions with no current OSV report.
- Replaced the unavailable `claude-agent-sdk` 0.1.39 lock with the exactly held, previously probed 0.1.44. The exact direct constraint prevents an unreviewed jump within the pre-1.0 SDK series; Dependabot can propose later versions for separate validation. The 0.2.x migration remains out of scope.
- Kept `fastapi = "^0.115.0"` and its resolved FastAPI/Starlette versions (0.115.14/0.46.2) unchanged.
- Removed the direct `anthropic` dependency. No source or test imports the Python `anthropic` package, and installed `claude-agent-sdk` 0.1.44 metadata requires only `anyio`, `mcp`, and (for Python below 3.11) `typing-extensions`; it does not require `anthropic`. The clean environment confirms `anthropic` is absent. `ANTHROPIC_API_KEY` handling and all authentication code are unchanged.
- Added weekly Dependabot updates for `pip` and `github-actions`. No auto-merge is configured.
- Added a full committed-lock OSV report using `google/osv-scanner-action` 2.7.1 at commit `32d3cd482bdadfb38b186c0ad1b031902d55d932`. There is no ignore file or package exclusion. SARIF upload is enabled; `fail-on-vuln: false` makes the report informational rather than silently declaring the documented residuals resolved.

## Verification evidence

- Baseline `poetry check --lock`: passed, but a cold-cache, empty-environment `poetry install --no-interaction --no-cache` failed with `Unable to find installation candidates for claude-agent-sdk (0.1.39)`. PyPI's version metadata endpoint returned HTTP 404.
- Refreshed `poetry check --lock`: passed (`All set!`).
- Refreshed clean install: a newly created Python 3.11.15 environment installed 68 locked packages plus the project with no cache. It contains SDK 0.1.44 and certifi 2026.11.20, and does not contain `anthropic`.
- Full suite in that clean environment: **391 passed** in 22.55s. One Starlette `BlockingPortal` deprecation warning remains; it does not fail the suite.
- `black --check src tests`, `isort --check-only src tests`, and `flake8 src tests`: passed.
- New CI contract tests were watched fail before configuration was added, then passed with the existing workflow tests (11 passed).
